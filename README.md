# Computational Graphics and Visualization Portfolio

## CS-330 Portfolio Reflection

### Software Design Approach
I approach software design by breaking problems into smaller pieces and focusing on how they fit together. For this project, I planned the scene by separating object creation, transformations, lighting, and camera controls. This made the project easier to manage and allowed the scene to grow without becoming difficult to maintain.

### Design Skills Developed
This project improved my ability to think in terms of scale, spacing, and realism within a 3D environment. I gained a better understanding of how lighting and textures affect how objects appear and how camera placement influences the overall scene.

### Design Process
I followed an iterative design process, starting with basic shapes and layout and then adding detail over time. Each milestone allowed me to review earlier work and make improvements based on testing and visual results.

---

### Development Approach
I develop programs by starting with a working foundation and improving it in small, controlled steps. During this project, I relied on frequent testing to make sure new changes did not break existing functionality.

### Development Strategies and Iteration
Developing in OpenGL required careful attention to transformations and lighting behavior. Iteration was important because small adjustments often had a large visual impact. Revisiting and refining code helped improve both clarity and realism.

### Growth Throughout the Milestones
As the project progressed, my development approach became more structured and intentional. Early experimentation evolved into focused changes that supported the final scene.

---

### Value of Computer Science
Computer science provides the tools needed to solve complex problems in a structured way. This project reinforced how programming concepts can be applied creatively while still following sound development practices.

### Educational and Professional Value
Computational graphics strengthened my understanding of how math, logic, and programming work together in real-time systems. These skills are valuable in both academic settings and professional areas such as simulation, visualization, and interactive software development.
